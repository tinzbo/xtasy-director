# 产品设计 · Xtasy Director 0.1

## 用户与交付

面向有产品图片、需要快速验证短片结构的独立创作者与小型品牌团队。一个项目从商品简报开始，到可下载的视频、封面、字幕、脚本和结构化项目结束。首版采用图片动效成片，交付范围在页面中明确展示。

## 核心流程

简报 → Jev 在三个内容结构中判断 → 生成可编辑分镜 → 上传或替换素材 → 保存版本 → 制作 MP4 与 ZIP → 从项目库继续迭代。

Jev 负责有限选项的语义匹配。模板负责文案结构和镜头编排，Sharp 负责画面，FFmpeg 负责视频。生成失败、无密钥、低置信度、缺少 FFmpeg 均有真实状态，用户可以选模板继续工作。

## 内容品类

| 内容结构 | 适合场景 | 交付方向 |
| --- | --- | --- |
| 静物编辑部 | 家居、器物、设计品牌 | 自然光、产品细节、留白文案 |
| 卖点直达 | 电商上新、功能型商品 | 卖点逐条展开、明确行动文案 |
| 日常的一幕 | 生活方式、社交短内容 | 场景开篇、使用过程、情绪收尾 |

## 首版验收

- 输入自己的产品信息后能产生不同镜头内容，镜头时长总和守恒。
- 可编辑字幕、说明、时长、素材，并在重新打开后保持。
- 导出真实 MP4，内容与保存版本一致；ZIP 包含可继续制作的文件。
- 无模型服务也能通过明确模板完成流程。

## 下一轮验证

邀请有真实上新任务的创作者实际制作。先记录从简报到首次导出的时间、导出成功率、每个项目的编辑次数和再次打开比例。收集成片可用性反馈后，再决定增加视频生成、配音或品牌模板。当前没有账户、支付、云端队列或公开部署，尚无付费和留存结论。
